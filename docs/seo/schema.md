# Structured data (JSON-LD)

All JSON-LD is generated by `src/build.py` from `src/site_data.py`, the same source as the visible text, so the NAP, services and towns can't drift. Each page has one `<script type="application/ld+json">` with an `@graph`. `build.py` parses every block with `json.loads` while building, so a malformed block fails the build.

## Blocks
| Node | Pages | Contents |
|---|---|---|
| `HomeAndConstructionBusiness` (`@id` `https://itoppavers.com/#business`) | every page | name, legalName (iTop Pavers LLC), url, logo (512 px PNG), images, telephone, email, PostalAddress, `openingHoursSpecification` (Mon–Fri 08:00–18:00, Sat 09:00–13:00), `areaServed` (the 12 towns, matching the visible list and the map exactly), description with the licence, `hasCredential` (licence CBC 1294954, recognised by the Florida DBPR), `knowsAbout` (the 10 services), `sameAs` (Instagram, Facebook). A LocalBusiness subtype is also an Organization, so this node covers the "Organization with logo" requirement. |
| `WebSite` (`/#website`) | every page | url, name, publisher → business |
| `WebPage` | every page | url, name, description, isPartOf → website, about → business |
| `Service` ×10 | home, `/services/`, each service page | name, serviceType, description (the answer-first paragraph), url, provider → business `@id`, areaServed, image |
| `FAQPage` | home (10 Qs), each service page (4 Qs), `/faq/` (all 52 Qs) | Only questions that are visible on that page |
| `BreadcrumbList` | every inner page | Matches the visible breadcrumb |
| `ImageGallery` | `/projects/` | The 12 real project photos |
| `Person` | `/about/` | Fabio, Manager, worksFor → business (TODO(client): confirm surname spelling) |

## Deliberately not included
- **No `AggregateRating` or `Review`.** Self-served review stars aren't eligible for rich results, and the user asked not to show the review count.
- `geo`, `priceRange`, `foundingDate` and the Google Business Profile URL in `sameAs` are left out until the client confirms them (marked TODO in `build.py` and `site_data.py`).

## How to re-test
1. Build and deploy, then open the **Rich Results Test** (https://search.google.com/test/rich-results) and test `/`, `/services/patios/` and `/faq/`. You should see: LocalBusiness, FAQ, Breadcrumb and no errors. Note that Google now shows FAQ rich results only for some government and health sites; the markup is still valid and useful to answer engines.
2. Open the **Schema Markup Validator** (https://validator.schema.org/) and paste each URL. It checks every type and property against schema.org.
3. Locally: `python3 src/build.py` fails if any block is not valid JSON. To eyeball a page: `python3 -c "import re,json;h=open('dist/index.html').read();print(json.dumps(json.loads(re.search(r'ld\+json\">(.*?)</script>',h,re.S).group(1).replace('<\\/','</')),indent=1)[:3000])"`
