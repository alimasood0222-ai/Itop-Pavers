## 301 redirects
| From | To | Why |
|---|---|---|
| `/services/outdoor-kitchens-2/` | `/services/outdoor-kitchens/` | Broken link on the old home and services pages (404) |
| `/get-a-quote` | `/get-a-quote/` | Old header buttons used the slashless URL (handled by `trailingSlash`) |
| `/home/` | `/` | Old WordPress page slug |
| `/paver-styles/` | `/styles/` | Defensive |
| `/gallery/`, `/portfolio/` | `/projects/` | The old FAQ mentioned a "gallery page" |
| `/contact-us/` | `/contact/` | Common variant |
| `/about-us/` | `/about/` | Common variant |
| `/cookies-policy/` | `/cookie-policy/` | Old footer label |
| `/sitemap_index.xml`, `/page-sitemap.xml`, `/wp-sitemap.xml` | `/sitemap.xml` | Old Yoast/WordPress sitemaps |

## Not redirected on purpose
- The 20 dead `sitemapNNN.xml` URLs from the old `robots.txt` were never real pages. Let them 404 so Google drops them.
- `/wp-login.php`, `/wp-admin/` and `/readme.html` should 404 on the new site.
