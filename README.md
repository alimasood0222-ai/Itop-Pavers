# iTOP Pavers website

A static multi-page site for **iTOP Pavers** (Jacksonville / St. Augustine / St. Johns County, FL), generated by a small Python build script. No framework and no npm build.

## Quick start
```bash
python3 src/build.py                    # writes dist/ (one folder per page)
cd dist && python3 -m http.server 8000  # open http://localhost:8000
```
Deploy: `cd dist && vercel deploy --prod --project itop-pavers`. `dist/vercel.json` carries the redirects, trailing-slash rule, cache headers and the `noindex` header for the preview domain.

## Structure
```
src/
  site_data.py   SINGLE SOURCE of facts and copy: NAP, hours, licence, services (page copy + FAQs),
                 towns, projects, paver collections, layers, patterns, comparison table, general FAQ
  build.py       Generator: renders every page + JSON-LD from site_data, plus sitemap.xml, robots.txt,
                 llms.txt, site.webmanifest, vercel.json, 404.html; copies assets
  styles.css     All CSS (self-hosted Poppins @font-face at the top)
  app.js         All JS. Guarded modules that ENHANCE the static HTML (nav, showcase, filters, lightbox,
                 paver explorer, quote form). Three.js is loaded lazily from /assets/vendor only after the
                 visitor interacts and a 3D canvas is near the viewport
  sprite.svg     SVG icon sprite ({{LOGO_SYMBOL}} is filled in from assets/logo)
  content/legal/ Privacy, Cookie and Terms text carried over from the old site (cleaned HTML)
assets/
  photos/        Real iTOP job photos (WebP, -sm = 720 px) + Fabio portrait
  pavers/        Tremron product textures, thumbnails (-t) and installed photos
  brand/         favicon, app icons, logo-512, og-image (1200×630), 3D poster images
  fonts/         Poppins 400/500/600/700 woff2 (latin)
  vendor/        three.min.js r128
docs/seo/        plan, redirects, schema, keyword map, off-site checklist, client questions
dist/            Build output. Never edit by hand.
```

## Pages
`/`, `/services/` + 10 service pages (old slugs kept), `/styles/`, `/projects/`, `/about/`, `/service-area/`, `/faq/`, `/contact/`, `/get-a-quote/`, the legal pages, two noindex thank-you pages, and `404.html`.

## Content rules
- Facts only from `site_data.py`. Anything unconfirmed is a `TODO(client)` (see `docs/seo/client-questions.md`).
- Never show the Google review count. No AggregateRating/Review schema.
- Only real iTOP photos are presented as iTOP work. Tremron product photos are credited.
